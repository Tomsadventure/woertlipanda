# Wörtli-Panda

Englisch-Wörtli der 4. Klasse (Schweiz) lernen mit Bao, dem Panda: Lernkarten, Hören, Wählen, Schreiben (Puzzle und Tastatur),
Memory und Wörtlitest. Jedes sichere Wort lässt im Bambuswald einen Bambus wachsen. Fürs iPad, iPhone und den PC;
läuft auch ohne Internet (Safari → Teilen → «Zum Home-Bildschirm»).

Dieser Ordner wird von `Scripts/bauen.py` im Projekt `Woertlipanda` erzeugt – hier nichts von Hand ändern, es wird überschrieben.
Bilder: OpenAI. Stimme: ElevenLabs. Schriften «Nunito» und «Andika» unter der SIL Open Font License (`fonts/OFL-*.txt`).
